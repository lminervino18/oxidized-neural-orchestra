# Abstract
Training deep learning models requires large computational resources and long execution times; the algorithms involved make intensive use of the CPU and demand very large memory capacities in order to store both the training data and the model itself. Together with the revolution in the application of artificial intelligence, minimizing this training time has become a pressing topic. To achieve this, the most scalable strategy is distributed execution.

The problem is that using a distributed optimization algorithm to train a deep learning model comes with challenges in designing the distribution strategy, and with worse (or directly unusable) convergence results if it is not done carefully. For instance, if the workload were distributed by data and each node optimized separately over the partition assigned to it, later combining the independently computed results, the model would not be optimized over the whole dataset, since each node would have incurred significant *overfitting* on its own partition. Moreover, those specialized solutions are not directly combinable by averaging their weights, because the result of each iteration of the optimization algorithms depends on the previous one.

Despite the existing difficulties, among them the ones already mentioned, there are several distributed solutions that manage to overcome them and provide large reductions in the execution times of training algorithms, by adding up the computing power and memory capacity of the nodes in the systems that run them. Nowadays, two of the most widespread solutions are *Parameter Server* and *All-Reduce*. *All-Reduce* is synchronous: at every step all nodes apply the same update, which favours the coherence of the optimization. *Parameter Server*, in contrast, centralizes the parameters and admits both synchronous and asynchronous variants; in its asynchronous mode it prioritizes the reduction of training time, at the expense of that coherence. Comparing both approaches, taking into account the variants of *Parameter Server*, is one of the axes of this work.

In this work these algorithms and their derivatives are studied, and a distributed training system is implemented to serve as a basis for their analysis and comparison, and as a starting point for the development of improvements.
