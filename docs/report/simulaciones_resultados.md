# Simulaciones y Resultados

Este capítulo pone a prueba el sistema descrito en el capítulo anterior. Primero se deriva, para cada estrategia de distribución, el tiempo de entrenamiento esperado a partir de un modelo analítico del costo de sincronización, y se lo contrasta con el medido sobre O.N.O. Luego se documenta la metodología de trabajo efectivamente seguida y las herramientas externas empleadas, y se cierra con los estudios experimentales que validan que las diferencias observadas entre estrategias son atribuibles al algoritmo y no a su implementación.
