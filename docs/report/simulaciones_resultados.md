# Simulaciones y Resultados

Este capítulo pone a prueba el sistema descrito en el capítulo anterior y se organiza en cinco partes. La primera describe la *metodología de experimentación y validación*: las pruebas automatizadas que verifican que el sistema hace lo que dice hacer y el entorno simulado sobre el que se toman todas las mediciones. La segunda detalla las *herramientas externas* empleadas y el criterio con que fueron elegidas. Sobre esa base, la tercera parte, *resultados*, deriva para cada estrategia de distribución el tiempo de entrenamiento esperado a partir de un modelo analítico del costo de sincronización y lo contrasta con el medido sobre O.N.O. La cuarta es un *estudio derivado* que analiza el impacto de los epochs offline sobre la convergencia, el tiempo de comunicación y la exactitud del modelo. El capítulo cierra con las *conclusiones*, que sintetizan en qué medida las diferencias observadas entre estrategias son atribuibles al algoritmo y no a su implementación.
